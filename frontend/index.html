The Universal High-Performance Matrix Runtime Compiler

Accelerate compute workloads across multi-core CPUs via a modern Rust shared memory backend tied seamlessly to Python via standard C-ABI.

$ powershell .\run_tritonx.ps1
INFERENCE RUNTIME BENCHMARK (ms) -- GFLOPS

Built in Rust Engine

Parallelized via Rayon thread pooling with cache-friendly tiling to eliminate memory bottlenecks.

High-Throughput C-ABI

Zero-copy CTypes memory passing straight from Python into high-performance compiled dynamic libraries.

Open Source Core

Fully customizable framework licensed for multi-threaded performance research and acceleration.
